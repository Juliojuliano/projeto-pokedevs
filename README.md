# Pokedevs

Página estática no estilo "Pokédex", com pokedevs (uma brincadeira com programadores) no lugar dos Pokémon. Ao clicar em um item da lista lateral, o cartão do pokedev correspondente é exibido com sua descrição.

## Tecnologias

- HTML5
- CSS3 (media queries para responsividade)
- JavaScript puro (DOM)

## Como visualizar

Não há dependências para instalar nem servidor para rodar. Basta abrir o arquivo `index.html` diretamente no navegador.

## Estrutura

- `index.html` — página principal
- `src/js/index.js` — lógica de seleção do pokedev
- `src/css/` — estilos (`reset.css`, `estilos.css`, `responsivo.css`)
- `src/imagens/` — imagens dos pokedevs e do fundo
